# 🔢 Calculator Project

This is a simple calculator project built using Python that can perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

## 🚀 Features
- Addition
- Subtraction
- Multiplication
- Division

## ▶️ How to Run

1. Clone the repository:
git clone https://github.com/ammarbeigh763-design/PyLab-AmmarBeigh

2. Navigate to the folder:
cd calculator

3. Run the program:
python calculator.py
